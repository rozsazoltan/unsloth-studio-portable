# Unsloth launcher icon

`icon.svg` is the editable source. The `.ico` and PNG sizes are raster exports of this artwork for Windows app, window, and notification-area integration.

## Artwork and attribution

The sloth illustration and launch badge are original artwork created for this companion. They do not copy or modify Unsloth's official logo. Unsloth is named only to describe compatibility; this artwork does not claim endorsement or affiliation.

## Export sizes

PNG previews: 16, 20, 24, 32, 48, and 256 pixels square. `icon.ico` contains those same six sizes. All exports use transparent corners and an embedded dark-green tile.
